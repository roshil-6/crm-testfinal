## ⚠️ IF SOMETHING DOESN'T WORK

### 1. Check the CMD Windows
- **Backend window** should show: `🚀 Server running on port 5002`
- **Frontend window** should show: `Compiled successfully!`

### 2. If Backend Won't Start
```cmd
cd server
node index.js
```
Look for error messages in the window.

### 3. If Frontend Won't Start
```cmd
cd client
npm start
```
Wait 30-60 seconds for compilation.

### 4. If Login Fails
- Make sure backend is running (check port 5002)
- Use the exact email and password from above
- Check the backend CMD window for error messages

### 5. If Site Can't Be Reached
- Make sure BOTH windows are open and running
- Wait 30-60 seconds after starting
- Try refreshing the browser
- Check firewall isn't blocking ports 3000 and 5002
