## Step-by-Step

### 1️⃣ Frontend to Vercel
- Go to vercel.com
- Import your repo
- Set Root Directory: `client`
- Deploy

### 2️⃣ Backend to Railway
- Go to railway.app
- Deploy from GitHub
- Set Root Directory: `server`
- Add PostgreSQL
- Set environment variables
- Initialize database

### 3️⃣ Connect Them
- Add `REACT_APP_API_URL` to Vercel
- Redeploy frontend

### 4️⃣ Test
- Check backend health
- Test login
